**Ссылка на дашборд:** https://datalens.yandex/47rtjz3mpglen?_share_link=public 

## Основные источники данных:

1. ГАС Выборы (http://izbirkom.ru/). Результаты выборов депутатов Государственной Думы Федерального Собрания Российской Федерации девятого созыва (выгрузка данных актуальна на 15:36 24.09.2026 г.);
2. ГАС Выборы (http://izbirkom.ru/). Результаты выборов депутатов Законодательного Собрания Санкт-Петербурга восьмого созыва (выгрузка актуальна на 18:43 22.09.2026 г.);
3. Сайт Санкт-Петербургской избирательной комиссии (http://www.st-petersburg.izbirkom.ru/);
4. Сайт "Выборы в Санкт-Петербурге (и вокруг него) 1993-2026 гг." (https://spb-elections.ru/)

## Особенности подготовительных процедур

**1. Сбор адресов и координат УИК и ТИК**. Актуальные постоянные адреса УИК в Санкт-Петербурге получены из сохраненных файлов по муниципальным газетам (взяты с spb-elections.ru); данные об экстерриториальных УИК получены из отчетных документов на сайте горизбиркома. Номера УИК, районы и адреса собраны в отдельный .xlsx-файл. Затем с помощью бесплатного API-ключа сервиса "JavaScript API и HTTP Геокодер" собраны координаты долготы и широты по каждому адресу (скрипт coord_script.py).

**2. Парсинг результатов голосования на выборах в ЗАКС и в Государственную Думу**. Операция выполнена с использованием двух инструментов: специально подготовленного интерпретатора обфусцирующего JS с сайта izbirkom.ru (election_stats_js_interpreter.py), а также краулера (election_stats_crawler.py), которы на сайте izbirkom.ru проходит по дереву комиссий и с помощью apps.cikrf.ru API и интепретатора JS собирает результаты по каждому УИК.

Архитектура краулера:
  1. challenge/get + challenge/solve — тривиальный proof-of-work
     (посчитать арифметическое выражение), выдает apiKey (JWT, живет
     10 минут). apiKey + fingerprint идут в заголовках всех запросов.
  2. commissionClassifiers — дерево комиссий (регион -> округа -> ТИК ->
     УИК). Лист (УИК) — узел с "type": 5.
  3. izbirkom.ru/reports/242?data=<...> — сырой отчет конкретного УИК
     (html+script с обфусцированными значениями).
  4. election_stats_js_interpreter.resolve_html — распознает 5 типов операций
     обфускации по ТЕЛУ JS-функций (не по случайным именам) и применяет
     их к дереву BeautifulSoup напрямую.
